# Module Guidelines

- Follow the module recipe in [02_Roadmap.md](../02_Roadmap.md#module-recipe).
- Navigation bar label: at most 2 lines x 10 characters, broken only between words (see [Naming Convention](../03_Naming_Convention.md#navigation-bar-labels)).
- Navigation bar icon: line icon drawn with `LineNavIcon` (`ui/navigation/NavIcons.kt`), 22 dp, stroke 1.8 dp.
- UI changes (look and behaviour) are proposed to the owner and approved before implementation.
